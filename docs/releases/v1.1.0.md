# corein 1.1.0 · Launch

🐉 **corein `1.1.0` “Launch”** is the first release of corein, a fork of nanoMuse 1.0.5 under a name, a look and a home of its own.

The agent, the relay and the apps are nanoMuse's work; this version changes what a person sees (the name, the circuit-o mark, the ids the systems know the apps by, the addresses they talk to) and fixes three things the desktop needed to work with Google Gemini. Everything else is as in nanoMuse 1.0.5, whose notes describe it.

## Highlights

- **corein.** The Android app installs as `com.corein.app`, the desktop as corein Desktop, the web console and the relay console carry the circuit-o mark. Links of the form `corein://…` open the app.
- **Bring your own key.** Sign in with an e-mail, then put a key of your own under *Settings → Models*: Google Gemini, OpenRouter, OpenAI, DeepSeek and the other providers of the catalogue. The relay does sign-in, the hub and conversation sync; it holds no model key and sees none of yours.
- **Gemini on the desktop works.** Model ids from Google's list no longer carry the `models/` prefix, the row tells the harness not to send a field Google rejects, and tool calls carry the signature Gemini 3 requires. The Gemini defaults are `gemini-3.5-flash-lite` for chat and the hands, which answers in about a second on the free tier.
- **Your own relay.** `bash scripts/self-host.sh` brings one up with TLS; the apps take its address under *Use a different server* on the sign-in screen.

## Upgrade Notes

- **A first install.** corein does not install over nanoMuse: the ids differ, so both can sit on one phone or one computer. Nothing moves from one to the other.
- **Android** `corein-1.1.0-arm64.apk` (Android 8.0+, arm64; versionCode 49) is signed with the project's key, the one every later version will carry. Verify with `sha256sum -c corein-1.1.0-arm64.apk.sha256`.
- **The desktop installers are not notarised.** On macOS open the app once from *System Settings → Privacy & Security → Open Anyway* (or right-click → *Open*); on Windows click *Run anyway*. They arrive a little after the APK (CI builds them from the tag), and `SHA256SUMS-desktop.txt` lists every checksum.
- **The built-in relay address** is `cloud.fomo.corein.in`. Until that relay is up, point the app at one of your own from the sign-in screen.
- **Where to get it.**
  | | |
  |---|---|
  | Android 8.0+, arm64 | `corein-1.1.0-arm64.apk` |
  | Windows 10+ | `corein-Desktop-1.1.0-win-x64.exe` |
  | macOS 12+ | `corein-Desktop-1.1.0-mac-arm64.dmg` / `-mac-x64.dmg` |
  | Linux x64 | `corein-Desktop-1.1.0-linux-x64.deb` / `.AppImage` / `.tar.gz` (run `./corein-desktop`) |
  | iPhone, iPad | build it yourself for now ([docs/ios.md](https://github.com/shaikfareed22/corein2026/blob/main/docs/ios.md)) |
