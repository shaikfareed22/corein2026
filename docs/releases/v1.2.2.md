# FOMO 1.2.2 · Harbor

**FOMO `1.2.2` “Harbor”** carries what Google Play asks of the Android app, and a relay you can run on a small server with the model provider you choose.

On the phone, a dialog now explains the accessibility service before Settings opens, and a reply can be reported from its long-press toolbar. On the relay, the model provider, the daily allowance and the currency are settings the operator changes from the admin page, and a busy provider is asked again before the app hears about it.

## Highlights

- **A disclosure before the accessibility settings.** Every place on Android that sends you to turn on the hands' accessibility service first says what the service does, when it runs and where screenshots go. Settings opens only from the dialog's consent button.
- **Report this reply.** Long-press an assistant reply on Android and choose *Report this reply*: a reason and an optional note go to the relay's operator, who reads them under the admin page's *Reports* tab.
- **The model provider is a setting.** The admin page's *Model provider* panel rotates the key or points the relay at another OpenAI-style provider without a restart, and tests the provider's model list first.
- **A daily allowance the operator sets.** Tokens per account per day are set from the admin page; members are not counted against it.
- **The relay names its currency.** Every app prints the relay's currency sign instead of a fixed ¥; a relay for India sets `CURRENCY=INR`.
- **A busy provider is asked again.** `CHAT_RETRIES` sends a request the provider answered with 429 or a 5xx again, waiting as long as the provider asks, and `CHAT_FALLBACK` sends the last try to another model.
- **A deploy kit for an AWS free-tier instance** under `cloud/deploy/aws-gemini/`: one `bootstrap.sh` that can be run again, with a README of the console steps.
- **Terms of service** at `docs/terms.md`, and a privacy page that names the relay's provider as the operator's choice.

## Upgrade Notes

- **Android installs over 1.2.1 and keeps your data.** `fomo-1.2.2-arm64.apk` (Android 8.0+, arm64; versionCode 52) is signed with the same key as 1.2.1. Verify with `sha256sum -c fomo-1.2.2-arm64.apk.sha256`.
- **`fomo-1.2.2.aab`** is the App Bundle Google Play takes, signed with the same key. It is not a file to install on a phone; use the APK for that.
- **The desktop app installs over 1.2.1.** The installers are not notarised: on macOS open the app once from *System Settings → Privacy & Security → Open Anyway*; on Windows click *Run anyway*. They arrive a little after the APK, and `SHA256SUMS-desktop.txt` lists every checksum.
- **A self-hosted relay** moves to 0.27.0 with `git pull` and `docker compose up -d --build`. The new settings (`CHAT_DROP`, `CHAT_RETRIES`, `CHAT_RETRY_MAX_S`, `CHAT_FALLBACK`, `CHAT_TOOL_CALL_SIGNATURE`, `CURRENCY`, `CURRENCY_SYMBOL`, `SUPPORT_EMAIL`, `TERMS_URL`) are optional; a relay that sets none of them behaves as before. Set `SUPPORT_EMAIL` so a report from a phone without an account has somewhere to go.
- **Where to get it.**
