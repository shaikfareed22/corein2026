# FOMO 1.2.0 · Rise

**FOMO `1.2.0` “Rise”** gives the agent its name and its logo.

The product called corein in 1.1.0 is FOMO now: the apps, the installers, the website and the docs carry the name and the logo. Nothing about how it works changed; the agent, the relay and your data are as they were.

## Highlights

- **FOMO.** The Android and iPhone apps, the desktop app and the web console are called FOMO, and their sign-in and first-run screens show the FOMO logo.
- **A new icon.** The launcher, the installers, the window icon and the favicon show the logo's O pierced by its orange arrow, on the logo's navy.
- **The website** at [fomo.corein.in](https://fomo.corein.in/) and the [docs](https://fomo.corein.in/docs/) carry the logo in their header and footer.

## Upgrade Notes

- **Android installs over 1.1.0 and keeps your data.** `fomo-1.2.0-arm64.apk` (Android 8.0+, arm64; versionCode 50) is signed with the same key as 1.1.0. Verify with `sha256sum -c fomo-1.2.0-arm64.apk.sha256`.
- **The desktop app installs over 1.1.0.** On Windows the program is now `fomo-desktop` and appears as FOMO in the Start menu; on macOS it is `FOMO.app`. The installers are not notarised: on macOS open the app once from *System Settings → Privacy & Security → Open Anyway*; on Windows click *Run anyway*. They arrive a little after the APK, and `SHA256SUMS-desktop.txt` lists every checksum.
- **Where to get it.**
  | | |
  |---|---|
  | Android 8.0+, arm64 | `fomo-1.2.0-arm64.apk` |
  | Windows 10+ | `fomo-Desktop-1.2.0-win-x64.exe` |
  | macOS 12+ | `fomo-Desktop-1.2.0-mac-arm64.dmg` / `-mac-x64.dmg` |
  | Linux x64 | `fomo-Desktop-1.2.0-linux-x64.deb` / `.AppImage` / `.tar.gz` (run `./fomo-desktop`) |
